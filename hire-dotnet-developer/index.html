What to include in your first message

You don’t need a finished specification. A few details are enough for a useful first reply:

  • What the software doesWho uses it and what the process is, in a few sentences.
  • The current stack.NET version, database, hosting and whether the code is in source control.
  • The problem or goalA bug, a slow area, a missing feature or an integration, and how you would know it is solved.
  • The kind of engagementA defined project, ongoing part-time work or a remote role, and any timeline or time-zone needs.

Please leave passwords, credentials and confidential client data out of the first email. We can agree how to handle access once we know the work is a fit.

How we would start

I reply with questions or a suggested next step. For an existing system, we then agree the scope, how I get access to the code and environments, what gets reviewed and how progress is shared. I would rather settle those points early than discover them mid-project.

I’m open to freelance projects and remote software development roles. If you are hiring for a role, send the stack and what the team needs from the developer.

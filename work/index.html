OPEN SOURCE PYTHON

InvoiceFlow

InvoiceFlow is an open-source Python toolkit that turns batches of PDF invoices into clean, structured, multi-sheet Excel workbooks. It uses parallel processing, pluggable extraction strategies and an OCR-ready parser layer.

It represents the same approach I bring to custom automation: make inputs, transformations and outputs explicit; keep the system practical to run; and design for the next integration or format change.
